# Supermarket Sales Analysis

## Project Overview

This project analyzes supermarket sales data to discover customer behavior, sales trends, and business insights using Python.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Features

* Data Cleaning
* Exploratory Data Analysis
* Data Visualization
* Sales Prediction

## Dataset

Supermarket Sales Dataset from Kaggle.

## Key Insights

* Most profitable product categories
* Popular payment methods
* Monthly sales trends
* Customer purchase patterns

## Machine Learning

Implemented Linear Regression for sales prediction.
